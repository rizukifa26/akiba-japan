加盟店の追加方法

店舗データ・写真・地図マーカーを追加する手順書

対象ファイル：src/data/shops.js　／　src/pages/shops.astro

1
写真をプロジェクトに保存する
public/ フォルダに画像ファイルを配置

プロジェクトの public/ フォルダ内に shops というサブフォルダを作り、そこに写真を入れてください。

public/
  shops/　← このフォルダを新規作成
    お店の名前-1.jpg　← 写真1枚目
    お店の名前-2.jpg　← 写真2枚目
    お店の名前-3.jpg　← 写真3枚目（任意）
ファイル名のルール：
日本語・スペースは使わないでください。半角英数字とハイフンのみ使用します。
例：akiba-shokudo-1.jpg　✓   　アキバ食堂 写真1.jpg　✗
推奨フォーマット：
横長（landscape）の JPG または WebP。1枚あたり 500KB 以下を目安にしてください。
2
shops.js に店舗データを追加する
src/data/shops.js を編集

ファイルを開くと、最後の方に以下のような記述があります。

// ← ここが最後の店舗データの終わり
  },
];

この }, と ]; の間に新しい店舗オブジェクトを追加します。

  },
  // ↓ ここから新しい店舗を追加
  {
    id: "akiba-shokudo",
    name: "アキバ食堂",
    category: "cafe",
    categoryLabel: "カフェ",
    description: "秋葉原の中心にある定食屋。日替わりランチが人気。",
    coinDiscount: 8,
    featured: false,
    lat: 35.6990,
    lng: 139.7725,
    images: [
      "/shops/akiba-shokudo-1.jpg",
      "/shops/akiba-shokudo-2.jpg",
    ],
  },
// ↑ ここまで。最後に必ず }, で閉じること
];

各フィールドの説明：

フィールド 内容 注意点
id 店舗の識別ID 半角英数字・ハイフンのみ。他の店舗と重複不可
name 店舗名（サイドバー・ポップアップに表示） 日本語・英語どちらでも可
category カテゴリの値（フィルター機能に使用） "parts" "cafe" "hobby" "community" のいずれか
categoryLabel カテゴリの表示名 "パーツ" "カフェ" "ホビー" "コミュニティ"
description 店舗の説明文（ポップアップに表示） 2〜3文が目安
coinDiscount Akiba Coin の割引率（数字のみ） 例：10 → 10% 割引
featured おすすめバッジの表示 true で「おすすめ」バッジが付く
lat 緯度（Google マップで取得） 例：35.6990
lng 経度（Google マップで取得） 例：139.7725
images 写真のパス（配列） "/shops/ファイル名.jpg" の形式で記述
Google マップで緯度・経度を調べる方法：
① Google マップで店舗の場所を開く
② 地図上で右クリック（スマホは長押し）
③ 表示された数字の 1つ目 = lat（緯度）、2つ目 = lng（経度）
よくあるミス：
① }, の末尾のカンマを忘れる
② id が他の店舗と同じになっている
③ 写真のパスが /shops/... でなく shops/... になっている（頭の / が必要）
3
shops.astro を編集して写真を表示する
src/pages/shops.astro の popupHTML 関数を修正

src/pages/shops.astro を開き、160〜164行目付近にある以下のコードを探してください。

【変更前】削除するコード：

const slides = [1, 2, 3].map((n) => `
  <div style="flex:0 0 100%;scroll-snap-align:start;height:160px;
              background:#f2f2f2;display:flex;flex-direction:column;
              align-items:center;justify-content:center;gap:6px;">
    ${photoIcon}
    <span style="font-size:10px;color:#c0c0c0;">写真 ${n}</span>
  </div>`).join("");

【変更後】置き換えるコード：

const imgs = shop.images && shop.images.length ? shop.images : [];
const slides = imgs.length
  ? imgs.map((src) => `
      <div style="flex:0 0 100%;scroll-snap-align:start;
                  height:160px;overflow:hidden;">
        <img src="${src}" alt="${shop.name}"
             style="width:100%;height:100%;object-fit:cover;" />
      </div>`).join("")
  : `<div style="flex:0 0 100%;scroll-snap-align:start;height:160px;
                background:#f2f2f2;display:flex;flex-direction:column;
                align-items:center;justify-content:center;gap:6px;">
      ${photoIcon}
      <span style="font-size:10px;color:#c0c0c0;">写真なし</span>
    </div>`;

修正後の動作：

店舗データの状態 ポップアップに表示されるもの
images: [...] が設定されている 実際の写真スライドショー
images がない、または空 グレーのプレースホルダー（写真なし）
4
動作を確認する
開発サーバーを起動してブラウザで確認

ターミナルで以下のコマンドを実行してください：

npm run dev

ブラウザで http://localhost:4321/shops を開き、地図上の新しいマーカーをクリックして写真が表示されるか確認してください。

確認チェックリスト：
✓ サイドバーに新しい店舗名が表示されている
✓ 地図上に新しいマーカーが表示されている
✓ マーカーをクリックするとポップアップが開く
✓ ポップアップに写真が表示されている
✓ カテゴリフィルターで正しく絞り込まれる
